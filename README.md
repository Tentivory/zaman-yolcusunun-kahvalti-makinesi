# ZAMAN YOLCUSUNUN KAHVALTI MAKİNESİ

## Dünyanın En Önemli Projesi (Belki de)

Bu repository, insanlığın en büyük sorununa çözüm bulmak için yaratıldı: **Hangi yıldan kahvaltı yiyeceğim?**

Zaman yolculuğu artık kahvaltı için mümkün! Bu makine, istediğin yıldan taze kahvaltı getirir. Tabii getirirken evreni biraz eğirir, ama kimse fark etmez.

### Özellikler
- ✅ Gerçekten çalışan kod (Python 3+)
- ✅ Rastgele absürt kahvaltılar
- ✅ Zaman paradoksu garantisi
- ✅ Hiçbir şey yapmaz ama çok ciddiye alınmalıdır
- ❌ Patates yok (yasaklandı)

### Kullanım
```bash
python kahvalti_makinesi.py
```

Sonra yıl gir, kahvaltın gelsin. Afiyet olsun!

### Uyarılar
- Bu makine kullanıldıktan sonra doğmamış olabilirsin.
- Yumurtalar pişmeden yenmiş olabilir.
- Kahvaltı yaparken gelecekteki kendini görebilirsin, selam ver.

### Katkıda Bulunmak
Pull request aç, yeni kahvaltı ekle. Ama dikkatli ol, belki çoktan eklendi.
